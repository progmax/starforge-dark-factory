# Long description

Starforge is a solo entry in the Pocketful track. It runs without outbound network or an external datastore. No browser UI or later-stage completion is claimed.

The public repository preserves agent commit history, four actual mandates, the unchanged full BAND room export, independent audit and safe failure/acceptance evidence. FACTORY.md explains setup, ownership and limits. Stage 1 took about two hours and thirteen minutes through final reconciliation. Provider token usage and billing are unknown.
